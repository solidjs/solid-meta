Solid Meta 2.0.0, the stable release for Solid 2.0. The version jumps to 2.0.0 to match `solid-js`, `@solidjs/web` and `@solidjs/router`: the `1.0.0-next.*` prereleases were this same line, and there is no stable 1.x. For Solid 1.x stay on `@solidjs/meta` 0.29.x.

Peer dependencies are now `solid-js` / `@solidjs/web` `^2.0.0`.
